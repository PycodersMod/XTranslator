# XTranslator 研究断点

日期：2026-10-23  
状态：`PAUSED_RESEARCH` / `NOT_IMPLEMENTED`

## 产品边界

XTranslator 是计划中的离线独立程序：输入已知 Loader 生态中的 Mod JAR，分析并在可验证范围内转换，输出新的 XLoader 原生 Mod JAR。它不属于 XLoader Runtime。此仓库的建立只保存研究断点，不表示开始产品实现。

## 讨论过的技术方向

- 纯 JAR 路径：分析字节码、Loader 元数据、Mixin/Transformer、访问转换、嵌入依赖、映射与注册行为等可观察证据；不能声称从字节码无损恢复任意源语义。
- 可选源码辅助：只有在用户授权、来源可信且许可证允许时匹配仓库、Revision、模块、构建配置和依赖，并记录来源链。
- 来源证据可分阶段记录：发现候选、仓库匹配、Revision 匹配、源码对应确认、构建来源验证。实际 Schema 尚未确认。
- 未来可研究 XSourceResolver 与 XSemanticTranslator 的分工；模型只作可解释辅助，转换质量由确定性编译和真实行为测试判定。
- 评估应区分源码检索、纯 JAR、可信源码辅助及恢复后转换，并分别记录识别、生成、可构建和真实执行证据。
- 不自动运行未审查的第三方构建脚本；对无法可靠转换的情况应明确返回 `PARTIAL` 或 `UNSUPPORTED`。

以上为历史讨论方向，不代表任何转换代码、模型、IR、规则映射或测试基线已经存在。

## 安全和恢复条件

只有用户明确解冻后才开展实现。禁止公开用户私有 Mod/JAR、源代码、凭据或未经授权的第三方源码；不应自动执行来源不明的构建脚本。每个转换结果需携带来源、工具版本、构建与真实运行证据；证据不足时必须如实标记。
